# 网上国网 通知
# 使用说明  
脚本是通过第三方小组件来实现的  
因为个人能力不足  
目前无法找到直接获取国网数据的方法  
只能多此一举

# 教程开始  
1.先安装所需要的App（链接会放下面）  
2.下载对应小组件导入App里  
3.在App里运行小组件填入对应信息  
4.确保能正常看到数据  
5.然后复制请求脚本订阅  
6.在Loon里打开脚本  
7.一定要选择“远程订阅”不是本地脚本  
8.把链接粘贴进去保存即可  
9.在添加定时脚本  
10.App里再次运行一次小组件  
11.让它把数据发送到Loon里  
12.Loon的定时脚本就能正常通知了  
13.然后桌面创建小组件把App里的小组件加上  
正常情况下只要小组件数据刷新了  
Loon这面也会更新  
不用每次都打开小组件发送数据
