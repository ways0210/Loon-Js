# 多平台热歌榜（测试版）
支持的平台  
抖音热歌 汽水音乐 QQ音乐  
网易云音乐 Applemusic Spotify 歌曲榜单
公益免费接口无需申请Api  
搭配Boxjs配置使用  
可以实现单平台或多平台同时推送  
实现3首 5首 10首 显示
如果不搭配Boxjs  
默认单次只推送一个随机平台  
固定歌曲数量10首  

歌单更新时间取决于上游接口

* 目前已知问题
* Applemusic接口不稳定有概率失败
