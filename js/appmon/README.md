# App应用更新监控
需要搭配Boxjs使用
* 填写App名称 id 地区代码 本地版本号
* 地区代码示例：CN US JP HK 等
* AppStore版本如果和本地版本号一样就不会通知
* 如果AppStore版号本高于本地就会通知
* 点击弹窗即可跳转商店更新
* 默认可监控3个App 只填一个也可以正常使用
