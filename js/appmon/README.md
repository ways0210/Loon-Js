# App 更新监控
需要搭配Boxjs使用
* 填写App名称 id 地区代码 本地版本号
* 地区代码示例：CN US JP HK 等
* 如果商店里的版本号和本地版本号一致就静默
* 只有商店里的版本号高于本地才会通知
* 点击弹窗即可跳转商店更新
* 默认可监控3个App 只填一个也可以正常使用
* App每次更新id都会变
* 需要始终和当前本地版本号对应
* 想要监控就需要更新后及时修改
