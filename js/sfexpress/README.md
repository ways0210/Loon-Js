## 说明

1. Loon 打开插件区块 添加获取Ck的订阅
2. 在复制定时脚本链接添加到Loon的脚本区块
3. 打开顺丰App > 我 > 积分
4. 提示 `获取会话: 成功`
5. 到Boxjs里查看是否已显示会话
6. 如果没看到或者没有
7. 先返回上一页或者重复第3步
8. 直到能够看到会话，然后按下载⏬箭头保存即可
9. 回到Loon运行测试脚本
